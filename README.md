# LL2Games RPG Client

WinAPI-based 2D RPG test client for LL2Games C++ game server.

## Purpose

This client is designed to test real-time server features such as login, character selection, channel entry, movement, chat, and inventory synchronization.

## Features

- Login
- Character selection
- Channel entry
- Player movement
- Chat
- Inventory UI

## Tech Stack

- C++
- WinAPI
- Visual Studio 2022
- TCP Socket
