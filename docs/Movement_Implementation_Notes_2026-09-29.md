## 구현 내용

- 서버 규격 6필드 입력 / 16필드 스냅샷 파싱과 검증.
- 플레이어·다른 플레이어·몬스터의 서버 위치 보간, epoch/tick 순서 검사.
- Alt 점프, 상하 탑승, 입력 변경 즉시 송신과 100ms heartbeat.
- 사망·기절·UI·포커스 상실 시 입력 차단, 부활·맵 이동·재접속 초기화.
- 서버 전달본의 3개 맵 발판·로프·사다리 및 포탈 데이터 적용.
- 점프·낙하·착지·탑승 모션 선택, 줄에서 정지 시 애니메이션 정지.
- 기존 좌표 이동 패킷과 이동 코드의 위치 덮어쓰기 제거.
- 디버그 발판·탑승 영역·객체 원점·발점 표시.

클라이언트는 중력을 직접 계산하지 않는다. 서버가 중력·충돌·점프 허용 여부를 결정하고 클라이언트는 입력 송신과 결과 표시를 담당한다.
