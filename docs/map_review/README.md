## 서버와 테스트

실제 중력·착지·탑승은 서버가 판정한다. 이 JSON만 바꾸고 기존 서버에 접속하면 표시선과 실제 충돌이 다를 수 있다.

[server_physics_proposal.json](server_physics_proposal.json)은 서버 담당자가 각 맵의 `physics`를 교체할 수 있도록 모은 **클라이언트 확정 좌표 전달본**이다. 서버에서 받은 export가 아니며 원본 해시도 기재하지 않았다. 서버에 같은 좌표를 적용하고 다시 export를 받아야 한다.

`docs/movement_data/maps.json`은 과거 서버 전달본으로 보존했다. 따라서 기존 `MovementTests.cpp`의 서버 전달본 일치 검사는 현재 제안안과 불일치하는 것이 예상된다. 이 검사를 통과시키려고 과거 전달본을 서버 반영 없이 덮어쓰지 않았다. 승인·서버 적용 후 최신 전달본으로 교체하고 기존 발판 3개/줄 2개 고정 기대값도 새 맵별 값으로 갱신한다.

`python docs/map_review/generate_preview.py`로 현재 맵 JSON의 경계·ID·상단 연결·복귀 발판을 검사하고 HTML/SVG/서버 제안본을 다시 생성할 수 있다. 코드를 실행할 때의 작업 폴더와 무관하게 저장소 경로를 사용한다.

현재 구조 검사: 세 맵 모두 통과. 실제 서버에서 이동 경로 전체의 도달 가능성과 착지·탑승을 검증한 결과는 아니다.

## 후속 플레이 검증 항목

1. 초록 발판이 원하는 표면·가장자리와 맞는지.
2. 노란 사다리의 위치·길이를 그림대로 유지할지, 플레이 편의를 위해 하단까지 연장할지.
3. 3번 맵 대각선 다리를 이번에는 충돌 없이 둘지, 후속으로 경사/계단형 발판을 구현할지.

검토 화면은 좌표 설계 확인용이며 게임 아트나 실행 코드를 수정하지 않는다.
